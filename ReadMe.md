# Getting Started

### Follow these steps to run the project locally.

1. Clone the repository

```
git clone https://github.com/zimagdy/pokedex.git
```

2. Navigate to the project directory

```
cd pokedex
```

3. Install dependencies

```
npm install
```

4. Run the program

```
npm run dev
```
